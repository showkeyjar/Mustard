🎯 结论与建议

CARM 规则路由优于 LLM zero-shot
94.6% vs 90.0%，CARM 在工具路由任务上比 gemma3:12b zero-shot 高出 4.6 个百分点。 特别是 calculator（94.4% vs 92.1%）和 code_executor（96.0% vs 100%）， 规则系统在结构化信号明确的场景下更可靠。
最高优先级修复：18 条共识 Bug
18 条人和 LLM 都认为 CARM 错了的 Bug 是 Phase 3 的首要修复目标。 主要集中在：(1) search↔bigmodel 边界 11 条，(2) code_executor 漏判 3 条， (3) 英文技术名词误判 3 条，(4) multi_intent 误触发 1 条。
人工标注的确认偏差
6 条 CARM+LLM 共同反对人工标注的案例，提示人工标注存在确认偏差—— 特别是 "分析" 开头的模糊查询，人工倾向标 search 但 LLM+CARM 都认为是 bigmodel_proxy。 建议对这 6 条进行人工复核。
